# NOVA PAY Android 1.0
Application Android Kotlin + Jetpack Compose. Direction artistique : noir, or, bleu nuit, argent et violet.

Fonctions incluses : tableau de bord, solde fictif, carte virtuelle de démonstration, verrouillage visuel local, activité, profil et navigation.

Limites : cette version ne crée pas de compte financier réel, ne stocke pas de fonds, n'émet pas de carte Visa/Mastercard et ne réalise aucun paiement. Ces fonctions nécessiteront un prestataire agréé, les contrôles réglementaires applicables et une intégration serveur sécurisée.

Compilation : ouvrir le dossier dans Android Studio (JDK 17, Android SDK 35), puis lancer `assembleDebug`.
